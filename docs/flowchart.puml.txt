@startuml
|Календарь событий|
start
:Выбрать ближайшее событие из календаря\nи продвинуть модельное время Tтек;

if (Тип события?) then (Генерация заявки от Иi)
    |Источник (ИБ)|
    :Создать заявку (i, N)\nи сгенерировать время следующей\nзаявки по закону Пуассона (ИЗ1);
    |Календарь событий|
    :Добавить следующее событие\nгенерации в календарь;
    |Диспетчер постановки (ДП)|
    :Принять заявку и зафиксировать\nфакт генерации в статистике;
    |Буферная память (БП)|
    if (В буфере есть свободное место?) then (Да [Д1ОЗ2])
        :Записать заявку в конец очереди\n(на первое свободное место по порядку);
        |Диспетчер выбора (ДВ)|
        :Инициировать проверку возможности\nпостановки заявки на прибор;
    else (Нет, БП полон [Д1ОО5])
        |Диспетчер постановки (ДП)|
        :Отправить вновь пришедшую заявку\nв отказ без изменения БП (Д1ОО5);
        :Увеличить счётчик отказов источника Иi;
        stop
    endif
else (Освобождение прибора Пk)
    |Приборы (П)|
    :Завершить обслуживание заявки,\nперевести прибор Пk в состояние СВОБОДЕН;
    :Зафиксировать время обслуживания\nи пребывания заявки в статистике;
    |Диспетчер выбора (ДВ)|
    :Получить триггер освобождения прибора;
endif

|Диспетчер выбора (ДВ)|
if (Буфер пуст?) then (Да)
    :Ожидать следующего события;
    stop
else (Нет, в БП есть заявки)
    :Поиск свободного прибора\nпо приоритету номера от П1 до Пm (Д2П1);
    if (Найден свободный прибор Пk?) then (Нет, все заняты)
        :Оставить заявки в БП\nдо освобождения прибора;
        stop
    else (Да, прибор Пk свободен)
        |Буферная память (БП)|
        if (Есть активный нерасширяемый пакет?) then (Нет / Пакет исчерпан)
            :Найти в БП заявки источника\nс наивысшим приоритетом (min № источника);
            :Сформировать новый пакет из всех\nтекущих заявок этого источника в БП (Д2Б5);
        else (Да, в пакете есть заявки)
        endif
        :Извлечь первую заявку текущего пакета из позиции N;
        :Сдвинуть все заявки с позиций N+1..конец\nна одну позицию влево (Д1ОЗ2);
        |Диспетчер выбора (ДВ)|
        :Передать выбранную заявку на прибор Пk;
        |Приборы (П)|
        :Занять прибор Пk и рассчитать Tобсл\nпо равномерному закону (ПЗ2);
        |Календарь событий|
        :Запланировать событие освобождения\nприбора Пk в момент Tтек + Tобсл;
        stop
    endif
endif
@enduml
