@startuml
autonumber
skinparam style strictuml
skinparam SequenceMessageAlignment center

actor "Календарь событий\n(Таймер / Контроллер)" as Calendar
participant "Источник (ИБ)" as Source
participant "Диспетчер постановки\n(ДП)" as DP
queue "Буферная память\n(БП)" as Buffer
participant "Диспетчер выбора\n(ДВ)" as DV
participant "Приборы\n(П1..Пm)" as Devices
participant "Модуль статистики" as Stats

== 1. Генерация заявки и постановка в буфер (ИЗ1, Д1ОЗ2, Д1ОО5) ==

Calendar -> Source: Триггер: наступило время генерации Tвх
Source -> Source: Создание заявки (id источника, № заявки)\nи расчёт следующего Tвх по закону пуассона [ИЗ1]
Source --> Calendar: Новое событие генерации запланировано (Tвх_next)

Calendar -> DP: Триггер: поступление новой заявки в СМО
DP -> Stats: Зафиксировать сгенерированную заявку
Stats --> DP: OK

DP -> Buffer: Проверка наличия свободных мест (hasFreeSpace)
alt Есть свободное место в БП [Д1ОЗ2]
    Buffer --> DP: true (свободно место в конце очереди)
    DP -> Buffer: Поставить заявку в конец очереди [Д1ОЗ2]
    Buffer --> DP: Заявка записана в ячейку K
    DP --> Calendar: Постановка в БП завершена (триггер проверки обслуживания)
else Буфер полностью заполнен — Отказ [Д1ОО5]
    Buffer --> DP: false (свободных мест нет)
    DP -> Stats: Зафиксировать отказ для вновь пришедшей заявки [Д1ОО5]
    Stats --> DP: Статистика отказов обновлена
    DP -> DP: Уничтожение (выход) вновь пришедшей заявки без изменения БП [Д1ОО5]
    DP --> Calendar: Обработка отказа завершена
end

== 2. Happy Flow и постановка на прибор (Д2П1, Д2Б5) ==

Calendar -> DV: Триггер: в БП появилась заявка ИЛИ освободился прибор
DV -> Buffer: Проверить, не пуст ли буфер (isEmpty)
Buffer --> DV: false (есть ожидающие заявки)

DV -> Devices: Поиск свободного прибора по приоритету номера (от П1 к Пm) [Д2П1]
alt Есть свободный прибор (Happy Flow / Освобождение прибора)
    Devices --> DV: Найден свободный прибор Пk (с минимальным номером) [Д2П1]
    
    DV -> Buffer: Проверить наличие активного нерасширяемого пакета [Д2Б5]
    alt Пакет уже сформирован и не пуст [Д2Б5]
        Buffer --> DV: Пакет активен (источник И_prio)
        DV -> Buffer: Извлечь первую заявку из текущего пакета\nсо сдвигом остальных заявок (N+1 -> N) [Д2Б5, Д1ОЗ2]
        Buffer --> DV: Заявка из пакета получена
    else Пакета нет (или предыдущий пакет полностью обслужен) [Д2Б5]
        Buffer --> DV: Активный пакет отсутствует
        DV -> Buffer: Найти источник с наивысшим приоритетом в БП\nи сформировать пакет из всех его текущих заявок [Д2Б5]
        Buffer --> DV: Пакет сформирован, извлечена 1-я заявка пакета\nсо сдвигом очереди (N+1 -> N) [Д2Б5, Д1ОЗ2]
    end
    
    DV -> Stats: Учесть время ожидания заявки в БП (Tож = Tтек - Tвх)
    Stats --> DV: OK
    
    DV -> Devices: Поставить выбранную заявку на прибор Пk [Д2П1]
    Devices -> Devices: Расчёт времени обслуживания Tобсл\nпо равномерному закону [ПЗ2]
    Devices --> DV: Прибор Пk занят до (Tтек + Tобсл)
    DV --> Calendar: Запланировать событие освобождения прибора Пk
else Все приборы заняты
    Devices --> DV: null (свободных приборов нет)
    DV --> Calendar: Ожидание освобождения любого прибора (заявка остаётся в БП)
end

== 3. Завершение обслуживания на приборе ==

loop Пока в системе происходят события освобождения приборов
    Calendar -> Devices: Триггер: наступило время освобождения прибора Пk
    Devices -> Devices: Завершить обработку текущей заявки, перевести Пk в статус FREE
    Devices --> Calendar: Заявка обслужена, прибор Пk свободен
    Calendar -> Stats: Учесть время обслуживания (Tобсл) и время в системе (Tвс)
    Stats --> Calendar: Статистика обновлена
    Calendar -> DV: Триггер: прибор Пk освободился (вызов блока 2 для следующей заявки пакета) [Д2Б5]
end
@enduml
